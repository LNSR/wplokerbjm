# Lowker-site

This repository contains the source code and configuration for the Lowker-site project.  
It includes a WordPress setup with custom themes and child themes for job listing functionalities.

## Structure

- `wordpress/themes/astra`: Main Astra theme files.
- `wordpress/themes/astra-child`: Customizations and overrides for the Astra child theme.

## Usage

1. Clone the repository.
2. Set up a local WordPress environment.
3. Copy the themes into your WordPress installation's `wp-content/themes` directory.
4. Activate the Astra or Astra Child theme as needed.

## Customization

Modify the child theme for custom features and styles.  
Refer to the theme documentation for further customization options.
