# VS Code Keyboard Shortcuts for Navigation

## File Navigation
- `Ctrl+P`: Quick Open, Go to File
- `Ctrl+Tab`: Navigate between open files
- `Ctrl+Shift+Tab`: Navigate backwards between open files
- `Ctrl+PgDn`/`Ctrl+PgUp`: Switch between tabs
- `Alt+Left`/`Alt+Right`: Go back/forward in navigation history

## Code Navigation
- `F12`: Go to Definition
- `Alt+F12`: Peek Definition
- `Shift+F12`: Go to References
- `Ctrl+G`: Go to Line
- `Ctrl+Shift+O`: Go to Symbol in file
- `Ctrl+T`: Go to Symbol in workspace
- `Ctrl+[`/`Ctrl+]`: Indent/outdent line
- `Ctrl+Home`/`Ctrl+End`: Go to beginning/end of file

## Editor Navigation
- `Ctrl+\`: Split editor
- `Ctrl+1`/`Ctrl+2`/`Ctrl+3`: Focus 1st, 2nd, 3rd editor group
- `Ctrl+F4`: Close current editor
- `Ctrl+K Z`: Zen Mode (distraction-free coding)
- `Ctrl+K F`: Close folder

## Interface Navigation
- `Ctrl+B`: Toggle sidebar visibility
- `Ctrl+Shift+E`: Explorer view
- `Ctrl+Shift+F`: Search view
- `Ctrl+Shift+G`: Source Control view
- `Ctrl+Shift+D`: Debug view
- `Ctrl+Shift+X`: Extensions view
- `Ctrl+J`: Toggle terminal panel

## Keyboard Tricks for Navigating Code

- `Ctrl+Shift+\`: Jump to matching bracket
- `Ctrl+Shift+.`: Navigate between symbols in current file
- `Alt+F12`: Peek implementation
- `Ctrl+Space`: Trigger intellisense suggestions
- `Ctrl+K Ctrl+I`: Show hover information
- `Ctrl+K F12`: Open definition to the side
- `F8`/`Shift+F8`: Navigate between errors/warnings
- `Ctrl+U`: Move cursor back to previous position
- `Alt+Click`: Add multiple cursors
- `Ctrl+D`: Select next occurrence of current selection
- `Ctrl+F2`: Select all occurrences of current selection
## Advanced Navigation

- `Ctrl+K Ctrl+C`: Add line comment
- `Ctrl+K Ctrl+U`: Remove line comment
- `Ctrl+/`: Toggle line comment
- `Shift+Alt+A`: Toggle block comment
- `Ctrl+Shift+V`: Preview Markdown
- `Ctrl+K V`: Open Markdown preview to the side
- `Ctrl+Shift+[`/`Ctrl+Shift+]`: Fold/unfold region
- `Ctrl+K Ctrl+0`: Fold all
- `Ctrl+K Ctrl+J`: Unfold all
- `Ctrl+K Ctrl+[`/`Ctrl+K Ctrl+]`: Fold/unfold recursively
- `Ctrl+M`: Toggle Tab key moves focus
## Quick Line Navigation

- `Ctrl+G`: Go to specific line number
- `Alt+G Alt+G`: Go to line with column
- `Ctrl+L`: Select current line
- `Alt+Up`/`Alt+Down`: Move line up/down
- `Shift+Alt+Up`/`Shift+Alt+Down`: Copy line up/down
- `Ctrl+X`: Cut line (when nothing is selected)
- `Ctrl+Enter`: Insert line below
- `Ctrl+Shift+Enter`: Insert line above
- `Home`/`End`: Go to beginning/end of line
- `Ctrl+Home`/`Ctrl+End`: Go to beginning/end of file
## Multi-key Combinations

- `Ctrl+K Ctrl+S`: Open keyboard shortcuts
- `Ctrl+K Ctrl+T`: Change color theme
- `Ctrl+K M`: Change file language
- `Ctrl+K R`: Reveal active file in Explorer
- `Ctrl+K O`: Open active file in new window
- `Ctrl+K P`: Copy path of active file
- `Ctrl+K Ctrl+X`: Trim trailing whitespace
- `Ctrl+K Ctrl+F`: Format selected text
- `Ctrl+K Ctrl+K`: Delete all lines after cursor
- `Ctrl+K Ctrl+L`: Toggle fold of current region
- `Ctrl+K Ctrl+Q`: Go to last edit location
- `Ctrl+K Ctrl+W`: Close all editors
- `Ctrl+K Enter`: Keep editor open
- `Ctrl+K Down`: Move active editor to bottom group
- `Ctrl+K Left/Right`: Move active editor to previous/next group
